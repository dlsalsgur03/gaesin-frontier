# 실시간 연결 (Socket.IO)

브라우저와 백엔드 사이의 실시간 알림 통로다. 채팅 메시지 전달과, 다른 팀원의 변경을 새로고침 없이 반영하는 데 쓴다.
**클라이언트가 보내는 이벤트는 없다.** 데이터 변경은 모두 REST로 하고, 서버는 커밋이 끝난 뒤 알림만 보낸다.

## 연결

- 주소: 백엔드와 같은 포트(기본 3001), Socket.IO 기본 경로 `/socket.io`, 기본 네임스페이스.
- 인증: 핸드셰이크에 브라우저가 붙여 보내는 `access_token` 쿠키(REST와 같은 JWT). 프론트는 `withCredentials: true`로 연결한다.
  토큰은 HttpOnly 쿠키라 스크립트가 읽지 않으며, URL이나 `auth` 필드로 보내지 않는다.
- 출처 검사: 웹소켓에는 CORS가 적용되지 않으므로 `Origin`이 `CORS_ORIGIN` 목록에 없으면(또는 없으면) 연결을 거부한다.
  다른 사이트가 사용자의 쿠키로 연결하는 것(CSWSH)을 막는다.
- 거부: 쿠키가 없거나 JWT가 유효하지 않으면 `connect_error`의 `err.data`가 `{ code: 'UNAUTHENTICATED', message }`다.
- 만료: 토큰이 만료되는 시각에 서버가 연결을 끊는다(`io server disconnect`). 프론트는 `/auth/me`로 로그인을 확인해
  유효하면 다시 연결하고, 401이면 로그인 화면으로 보낸다. 로그아웃하면 프론트가 연결을 끊는다.

## 룸

연결되면 서버가 `user:{userId}`와 소속된 모든 `team:{teamId}`에 넣는다. 클라이언트는 룸에 입장·퇴장 요청을 하지 않는다.

| 시점 | 처리 |
| --- | --- |
| 팀 생성·참여 | 그 사용자의 열린 연결을 `team:{id}`에 넣는다 |
| 탈퇴·내보내기 | 그 사용자의 연결을 `team:{id}`에서 빼고 `team:removed`를 보낸다 |
| 팀 삭제 | `team:{id}` 전체에 `team:removed`를 보내고 룸을 비운다 |

## 서버 → 클라이언트 이벤트

| 이벤트 | 대상 | 내용 |
| --- | --- | --- |
| `message:new` | 팀 룸(보낸 사람 포함) | 저장된 채팅 메시지. 형식은 `../chat/README.md` |
| `team:changed` | 팀 룸(변경한 사람 포함) | `{ teamId, scopes }`. 범위만 알리고 내용은 보내지 않는다 |
| `team:removed` | 떠난 사용자 또는 삭제된 팀의 룸 | `{ teamId }`. 그 팀 화면을 닫는다 |

`team:changed`의 `scopes`(하나 이상)와 보내는 시점:

| scope | 보내는 시점 | 프론트가 다시 불러오는 것 |
| --- | --- | --- |
| `team` | 이름 변경, 참여, 탈퇴·내보내기, 소유권 이전, 초대 코드 재발급 | 팀 목록, 팀룸 머리글·팀 정보, 캘린더(팀 이름·참여한 팀의 과제) |
| `assignments` | 팀 과제 등록·수정·삭제, 할 일 등록·수정·삭제, 탈퇴·내보내기(담당자 미배정) | 팀 과제 목록·상세, 캘린더 |
| `files` | 팀 파일 올리기·연결 변경·삭제, 팀 과제 삭제(연결 해제) | 팀 파일 탭, 과제의 연결된 파일 |
| `schedules` | 팀 일정 등록·수정·삭제 | 팀룸 일정 탭, 캘린더 |

프론트는 이 알림을 받으면 지금 화면을 그대로 보인 채 REST로 다시 불러온다(열린 채팅·입력 내용 유지).
캘린더 탭은 모든 팀의 `assignments`·`schedules`·`team` 변경과 `team:removed`를 받아 보고 있는 달을 조용히 다시 불러온다.

## 구현

`realtime.gateway.ts`의 `RealtimeGateway`가 연결 인증·룸 관리와 알림 메서드(`joinTeam`, `leaveTeam`, `closeTeam`,
`teamChanged`, `emitToTeam`)를 제공한다. 서비스는 이 메서드를 DB 커밋 뒤에 부른다.
서버 한 대를 전제로 한다. 여러 대로 늘리면 Socket.IO 어댑터(예: Redis)가 필요하다.
